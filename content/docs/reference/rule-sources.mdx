hl-tools follows Hyperliquid's rules: how many decimals an amount takes, what a send or a withdrawal costs, how a signature is built, how long a vault deposit is locked. Each group of rules below says where it comes from and when it was last checked against Hyperliquid's docs.

The "Last verified" date at the top of each tool links here. When Hyperliquid changes a rule, the rule set's version goes up and the change is listed under it. The figures themselves are on [Hyperliquid's numbers](/docs/reference/numbers).
