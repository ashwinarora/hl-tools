## The paste box

The box on the [home page](/) opens the right tool for whatever you paste:

| You paste | It opens |
| --- | --- |
| A transaction hash (`0x` + 64 hex) | Cross-layer Trace |
| An address (`0x` + 40 hex) | Multisig Inspector |
| A token ID (`0x` + 32 hex), a symbol or an asset ID | Asset Resolver |
| CoreWriter action bytes (`0x01…`) | CoreWriter Workbench |
| A `ws://` or `wss://` URL | WebSocket Workbench |
| An `http(s)://` URL | RPC Capability Probe, or the Multisig for a proposal link |
| An exchange response, or an error such as "Price must be divisible by tick size" | Order Composer & Failure Explainer |
| A signed request with `action` | Signing Inspector |
| A multi-sig request or proposal | Multisig Inspector, or the Multisig for a proposal |

Pasted text is handed to the tool inside the page. It is not put in the link.

## What every tool shares

- **The network.** The header's **Mainnet** / **Testnet** switch picks the network. Every result says which network it was read on, and when. If you switch afterwards, the tool says the result is from the other network.
- **Samples.** Each tool has samples to try it with. A sample may switch the header to its own network.
- **Links you can share.** Some tools put what you entered into the link (for example `?q=` or `?tx=`), and some have a **Share** button that puts the whole state into the link after `#`, which browsers do not send to the site. A pasted payload is put in a link only when you press **Share**.
- **Last verified.** Each tool's header shows when its rules were last checked against Hyperliquid's docs, and links to the [Where the rules come from](/docs/reference/rule-sources): every rule set with its sources and changelog.

## Good to know

<Accordions>
<Accordion title="Where requests go">
The tools ask Hyperliquid's public API and WebSocket, and any HyperEVM RPC endpoint you give them, straight from your browser. Those services see your IP address and what you ask.
</Accordion>
<Accordion title="Recorded sessions">
The WebSocket Workbench can record sessions. They are kept in this browser until you delete them.
